## ✨ Fitur Utama Website
* **Dynamic Project Showcase:** Menampilkan daftar proyek (termasuk proyek-proyek unik seperti *Dead Desk*, *InfinityFlow*, dll.) lengkap dengan deskripsi, tech stack, dan link ke repository.
* **Interactive Skill Badges:** Visualisasi keahlian teknologi yang dikuasai secara menarik dan scannable.
* **About Me & Journey Timeline:** Cerita singkat mengenai latar belakang, ketertarikan di dunia coding, serta linimasa pengalaman/edukasi saya.
* **Responsive & Mobile-First Design:** Dioptimalkan dengan sempurna agar nyaman diakses dari perangkat apa pun, mulai dari smartphone hingga layar desktop.
* **Contact Form / Social Links:** Memudahkan rekruter atau kolaborator untuk langsung terhubung dengan saya melalui Email, LinkedIn, atau platform lainnya.

---

## 🛠️ Tech Stack yang Digunakan
* **Struktur & Konten:** HTML5 (Semantic Tags untuk SEO yang lebih baik)
* **Desain & Animasi:** CSS3 (Flexbox, Grid, Custom Variables untuk kemudahan tema)
* **Logika & Interaktivitas:** Vanilla JavaScript (ES6+) untuk menangani manipulasi DOM, animasi gulir (*scroll animations*), dan logika navigasi.
